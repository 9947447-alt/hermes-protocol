## 游戏快速启动指南

本项目为纯前端独立架构（HTML5 + CSS3 + Vanilla ES6 JavaScript），无需安装任何额外依赖或服务端。

在终端中执行以下命令即可直接启动游玩：
```bash
open /Users/a0000/Developer/hermes-protocol/index.html
```
或者在访达（Finder）中进入 `/Users/a0000/Developer/hermes-protocol` 目录，双击 `index.html` 在任意现代浏览器中运行。

* 👁️ **充血偏振**：通过眼底充血状态过滤荧光素涂层干扰，还原被逆反期患者写反的文字。
* 🌀 **摩尔纹干涉**：心率超频下的底层微缩码检视工具。

### 3. 多层规则矩阵

## 快捷功能
* **单步回溯 (Rewind 1 Step)**：界面顶部和选项区均配备快捷「⏪ 回溯」按钮，可一键退回上一个选择点，并完整恢复当时的生理体征与物品状态，极大提升推理解密探索体验。
* **音效切换 (Web Audio)**：实时代码合成的环境白噪声、心跳声、报警蜂鸣与按键反馈。
* **CRT 滤镜切换**：一键切换复古高对比度扫描线视觉体验。
* **节点图谱 (Timeline & Jump)**：可查看已解锁的 9 大结局，并随意跳转至任何已探索过的历史时空锚点。
